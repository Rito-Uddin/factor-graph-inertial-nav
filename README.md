# factor-graph-inertial-nav
**Le contexte & l'objectif :** estimation d'état 3D d'un système autonome en environnement GNSS-denied via l'optimisation par graphes de facteurs (iSAM2 / GTSAM).
**Le socle théorique :** mentionne brièvement la modélisation sur les groupes de Lie $\mathrm{SO}(3)$ et $\mathrm{SE}(3)$, ainsi que la préintégration continue des mesures inertielles (en citant l'article de référence de Forster et al., 2016).  
**Un schéma du graphe :** **à mettre dés que je commencerais le projet**
*(un diagramme simple (en Markdown Mermaid ou image) montrant les nœuds d'état (x_k, v_k, R_k), les facteurs IMU entre deux pas et les facteurs de mesure absolue intermittents.)*
